# Primary Objective 1

The cell-level provenance contract is in [DASHBOARD_SPEC.md](../../DASHBOARD_SPEC.md), section 1. All runtime selectors are in config.yml; paths are in the shared output registry. The eight numbered sections retain the written slide map; laboratory slides use one Variable Explorer. No historical output is reconstructed.

`metadata/claims.yml` holds investigator-authored interpretations from the specification, initially draft. Human review supplies reviewer identity and the evidence hash after checking the selected run. `metadata/figures.csv` is intentionally header-only because no real figure paths are available. Candidate mappings are separate audit outputs and require curation.
