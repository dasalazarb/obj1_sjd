# Graph03 source characterization contract

`graph03_characterization_v1` adds source-level tiers without changing the
historical `validation_role` vocabulary. In particular,
`independent_baseline_anchor` still means held out with no declared conflict;
it is **not** an independence approval. Consumers performing inference must use
the new reviewed gate. R0 remains primary, R2 provisional, and R1/R3/R4 technical
comparators. No clinical association selects a representation or source panel.

The inventory is unique by frozen run, representation and source column:

| Tier | Interpretation | Inferential gate |
| --- | --- | --- |
| N1_DEFINING | Exact source/encoded feature in the frozen discovery panel | Blocked: internal structure |
| N2_RELATED | Documented source, derivation, instrument or reviewed proxy link to N1; Pop is dependent descriptive context | Blocked: related description |
| N3_CANDIDATE | Prespecified observed anchor without a declared N1/N2 conflict | Blocked: INDEPENDENCE_REVIEW_PENDING |
| N3_REVIEWED | Explicit source, lineage, proxy, origin, discovery exclusion and baseline review | Still requires original stability, observed support, model eligibility and multiplicity gates |
| PENDING_REVIEW / UNAVAILABLE | No prespecified independent role, insufficient provenance, adjustment context, absent or all-missing source | Blocked |

Adjustment is an orthogonal role; direct discovery inclusion always wins.
Baseline evidence does not approve longitudinal measurement dates. Pop labels,
including invalid/unrecognized labels, are consumed unchanged.

## Typed lineage

Exact frozen feature/source links define N1. Qualified semantic/derivation IDs
and documented instruments can connect sources; generic domain, family, LAB and
fallback instrument/subdomain groups cannot. Registry edges record their frozen
table and metadata field. Explicit relationships require a source citation;
clinical proxies also require APPROVED review and a reviewer. Paths retain edge
type and source citation. Cycles terminate. Reversing a derivation and then
following another derivation is forbidden: two independent inputs of Pop do
not become the same construct through their shared composite. Explicit
same-instrument evidence can still establish their appropriate relationship.

The validation config lists exact ESSPRI/SF-36 instrument sources and Pop's
published dependencies. It does not use column-prefix similarity as evidence.
Sources not used by a representation do not inherit N1 from another one.

## Review records

`characterization.independence_reviews` is empty in the distributed config.
A review record requires exact `representation_id` and `source_column`,
`reviewer`, `source_reference`, `baseline_window`,
`temporal_baseline_status: VERIFIED`, and all of:

- `lineage_review_status: APPROVED`
- `clinical_review_status: APPROVED`
- `origin_review_status: APPROVED`
- `proxy_review_status: APPROVED`
- `discovery_exclusion_review_status: APPROVED`

These are documented human decisions, never values generated by Graph03.
Review the frozen release and all source/proxy paths before supplying them.
New N1/N2 conflicts override an old approval. Review records are representation
specific; longitudinal `temporal_resolution.endpoint_policies` remain separate.
Synthetic tests attest only invented observations and cannot approve clinical
sources. An absent edge cannot establish independence. No approval establishes
external clinical validity or causality.

## Products and disclosure control

The original CSVs and historical marker medians remain available. Additional
products are `03_graph_characterization_{role_inventory,tier_counts,
clinical_matrix,independence_audit,evidence_summary}.csv` and
`03_graph_characterization_qc.json`. The QC records frozen provenance, unchanged
release hashes, unique source keys, reconciled observed/missing counts, hard
membership denominators, limitations and exact sources requiring review.
Encoded feature counts and unique raw source counts are distinct; evaluable
patient counts use unions, never sums across sources. Continuous sources have
observed median/IQR; categorical sources have categories/proportions; literal
positive/negative observations have separate tested, positive, negative, unknown
and not-tested counts. Missing never means negative. Undocumented sampling
counts are not inferred. Units remain pending where the source has no review.

Separate N1/N2/N3 figures for R0/R2, a source-role crosswalk and an availability
figure each have PNG, PDF and exact aggregate CSV sources. N1 uses eight
prespecified markers, with separate axes for different units. Empty panels
state limitations. N3 distinguishes REVIEW_PENDING, NOT_ESTIMABLE and COMPLETE;
no unestimated confidence intervals or significance stars are drawn. IQRs are
observed descriptions, not confidence intervals. Clinical and availability
views use the same disclosure filter: a small count suppresses the entire
representation/source panel and its complements. A group at the publication
minimum also requires review. The same filter protects historical clinical
marker/domain/anchor figures generated by the pipeline. Internal aggregate CSVs
remain INTERNAL_RESTRICTED and are not approved publication tables.

## Execution and validation

Run only:

```sh
python src/studies/graph/03_graph_community_characterization.py
```

The reader requires a validated `latest_completed_02.json` and all frozen
artifacts/source hashes. This intervention does not rebuild Graph02 or modify
its code/configuration, Step10, datasets or endpoint date policy. In a checkout
without the clinical release, the command intentionally stops at
`MISSING_COMPLETED_GRAPH02_RELEASE`. Do not recreate clinical memberships to
work around missing inputs. The synthetic integration test runs Graph03 against
a hash-verified invented release, prohibits discovery refitting, verifies
unchanged release/pointer hashes and denominators, checks every new product and
preserves original contracts. The exact clinical run/SHA, 159-patient universe,
R0/R2 denominators and 35 unresolved Pop labels can be verified only in the
authorized environment containing that release; they are not fixture constants.

Implementation verification (2026-11-04): the Graph02/03 and topological
regression suite passed 255 tests. A final 22-test product/acceptance check
covered the latest observation-count and context-exclusion changes, frozen
release integration, and the empty-Mapper pipeline. `git diff --check` passed.
The real zero-argument run stopped at `MISSING_COMPLETED_GRAPH02_RELEASE` because
this workspace contains neither the completed clinical release nor its source
dataset. No real discovery run was launched and no clinical approval was added.
